# 智慧能源管理平台 — 模块地图（来自用户手册 V2.0）

厂商：深圳合众致达科技有限公司（合众云）
站点：https://shuibiao.jinying.com/
手册：《智慧能源管理平台--用户手册 V2.0(1).pdf》（91 页）

> 登录方式：用户名 + 密码 + **图形验证码**（web 端）。
> 防暴力破解：同一 IP 连续输错密码 10 次以上会被拉黑。
> 权限模型：分权（角色→菜单/按钮级权限）+ 分域（按建筑/单位层级的区域权限）。
> 涉及增删改及远程控制/参数下发的操作均有操作日志。

## 菜单/模块清单（遍历导航图）

### 3.1 权限管理（系统管理）
- 系统登录（web + 微信小程序）
- 角色管理（系统管理→用户权限→角色管理）
- 用户管理（系统管理→用户权限→用户管理）
- 个人中心（改手机号、改密码；密码规则 6-16 位含数字/字母）
- 系统日志

### 3.2 档案管理
- 建筑档案
- 建筑配表
- 采集设备
- 计量设备
- 商户档案
- 住户档案

### 3.3 数据采集管理
- 采集策略
- 数据查询
  - 抄表数据(电)
  - 抄表数据(水)
  - 抄表成功率
  - 手工补录(电)
  - 手工补录(水)
- 远程控制
- 参数下发
- 校时策略
- 通讯异常提醒

### 3.4 收费管理
- 领导视窗（收费视窗 / 能耗视窗 / 领导视窗入口）
- 费控模式
- 水电单价管理
- 开户管理
- 充值缴费
- 账单查询（电费账单 / 水费账单 / 公摊账单 / 其他账单 / 水电收支账单 / 收费通知单）
- 财务对账（收费查询 / 退费查询 / 充值统计 / 欠费统计 / 账目盘点）
- 销户管理
- 低余额提醒
- 报表查询

### 3.5 能耗管理
- 能耗总概览
- 建筑用能
- 支路用电（含线损分析）
- 支路用水（含漏水分析）
- 分项用能
- 配置能耗档案（建筑档案配置 / 水档案配置 / 电档案配置）

### 3.6 系统参数配置
- 项目参数
- 收费参数
